# Reference tools

- `common/`: deterministic stimulus and checksums.
- `vst-shim/`: independently written minimal VST interface.
- `airwindows-harness/`: Airwindows fixture generator.
- `soundfont-harness/`: `generate_tml.sh`, `generate_font.sh`, and `generate_synth.sh`.
- `pitch-harness/`: `smb/`, `stft/`, and `dywa/` generators.
