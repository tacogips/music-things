# music-things

Reusable, host-agnostic Rust synth and effect DSP crates.

- Crates extracted from [vactr](https://github.com/tacogips/vactr) so the
  synth and effect kernels can be reused outside the vactr engine.
- Rust ports of permissively licensed open-source synth and effect code, such
  as the components bundled with the Behringer KICK and IGNITE open firmware
  (Airwindows, TinySoundFont, pitch-shifting and pitch-tracking code), ported
  from their original upstream sources.

Every crate builds for `wasm32-unknown-unknown` and has no runtime
dependencies unless noted.

## Crates

| Package | Purpose | Upstream | License |
| --- | --- | --- | --- |
| `music-things-airwindows` | Batch 1 effects: 110 plugins, Acceleration through DitherMeDiskers (`catalog()` lists them) | [Airwindows](https://github.com/airwindows/airwindows) | MIT |
| `music-things-soundfont` | SoundFont synthesis and MIDI | [TinySoundFont](https://github.com/schellingb/TinySoundFont) | MIT |
| `music-things-pitch` | Pitch shifting and tracking | [stftPitchShift](https://github.com/jurihock/stftPitchShift), [dywapitchtrack](https://hackage.haskell.org/package/dywapitchtrack-0.1.0.1), [smbPitchShift](https://github.com/s60sc/ESP32_VoiceChanger) | MIT, MIT, WOL |
| `music-things` | Optional facade re-exports | — | MIT |

The facade has no default features. Enable the desired ports:

```toml
music-things = { version = "0.1.0", features = ["airwindows", "soundfont", "pitch"] }
```

Parity tests compare the ports against committed fixtures generated by reference
harnesses. See [tools/README.md](tools/README.md) for harness usage and the
`MUSIC_THINGS_REFS` upstream checkout location. Component revisions and full
license texts are in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Development

```sh
mise install

```
