## Key Pitfalls

- `dep:` feature syntax needs Rust 1.60 or newer (fine with 1.83). Do not create implicit features
  that share the dependency names.
- The facade must keep building with default features (no deps) and with `--all-features`, for wasm32 too.
- The batch-1 name list must come from the pinned file, not from the catalog, which would make the test circular.
- Do not run a workspace-wide `cargo fmt` that rewrites others' files. Use `cargo fmt --check` only as
  a gate, and report any failure to its owner.
